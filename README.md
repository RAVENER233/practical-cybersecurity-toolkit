# Practical Cybersecurity Toolkit

A collection of 10 Python defensive cybersecurity tools built with Python.

## Projects

1. Input Activity Recorder
2. File Scanner
3. Network Lab
4. File Encryption and Recovery
5. Malware Behaviour Monitor
6. File Integrity Monitor
7. Network Traffic Analyser
8. Backup and Recovery Guard
9. Android APK Analyser
10. Linux Persistence and Backdoor Auditor

## Requirements

- Kali Linux
- Python 3
- Virtual environment
- Dependencies in requirements.txt

## Installation

Activate the environment:

    source .venv/bin/activate

Install dependencies:

    python -m pip install -r requirements.txt
