
# Python Cybersecurity Lab

Welcome to my Python Cybersecurity Research Lab!

## Projects

### 1. Keylogger Research
Study keyboard events and local input logging.

### 2. File System Scanner
Scan files and calculate SHA-256 hashes.

### 3. Network Communication
Build a TCP client and server using Python sockets.

### 4. Encryption Research
Explore AES-256-GCM encryption and decryption.

### 5. Malware Behaviour Detector
Monitor directories and inspect running processes.

## Requirements

- Kali Linux
- Python 3
- Visual Studio Code
- Python virtual environment

## Installation

Activate the virtual environment:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Safety

All experiments are intended for authorized,
local cybersecurity research.

Original test files are preserved during
encryption experiments.

Network experiments use localhost.
